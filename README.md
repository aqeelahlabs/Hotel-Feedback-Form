# Hotel Feedback Form

A hotel feedback form where guests can share details about their stay, including personal information, why they chose the hotel, and ratings for service and food. Built as part of the freeCodeCamp curriculum.

## Live Demo

https://aqeelahlabs.github.io/Hotel-Feedback-Form/

## Features

- Personal information fields for name, email and age, with name and email required
- A radio button question asking if it was the guest's first stay
- Checkboxes for the reasons a guest chose the hotel, with "Reputation" pre-selected
- Dropdown menus to rate the service and food, defaulting to "Excellent"
- A comments box for extra feedback
- A submit button that sends the form data to the freeCodeCamp feedback endpoint

## What I Practised

- Building forms with the `form` element, including the `method` and `action` attributes
- Grouping related inputs with `fieldset` and `legend`
- Connecting labels to inputs using `for` and `id`
- Using different input types: `text`, `email`, `number`, `radio` and `checkbox`
- Adding validation with `required`, `min` and `max`
- Providing hints with `placeholder`
- Creating dropdowns with `select` and `option`, and a `textarea` for longer text
- Structuring the page with `header` and `main`
